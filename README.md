A [make.fun](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) entry: one funny passive-aggressive note a smart fridge leaves for its owner — a single line, dry, petty and specific.

## What it does

`main.py` (Python standard library only) writes exactly one line of plain text to `/output/entry.txt` — just the note itself:

> Your leftovers expired Tuesday. I kept them cold for six days anyway, out of spite and professionalism.

The note is 103 characters, one line, deterministic — the same output on every run.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```
